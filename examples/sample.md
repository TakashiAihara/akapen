# ラウンド制の検証

本文は現ラウンドの凍結スナップショットを出す。live のファイルは出さない。

## 決まっていること

- ラウンド = ファイル内容の凍結スナップショット
- コメントはそのスナップショット内の行に紐づく
  - 行番号はスナップショット内でのみ意味を持つ
  - 原文 (anchor) がラウンドをまたぐ唯一の手がかり
- ラウンドを切るのは人
- SSE は通知だけにする

## 表

| 項目 | passive | review |
|---|---|---|
| 本文 | live 追従 | 凍結 |
| コメント | 打てない | 打てる |
| 用途 | 読む | 指摘して渡す |

## コード

```ts
const snapshot = roundContent(file, review.currentRound);
```

## 段落

再アンカーを廃止したので、原文を探し直す経路そのものが無くなった。追従の精度を上げ続けるいたちごっこから抜けるのが目的で、精度の改善ではない。

書いている最中にファイルが変わってコメントが競合する経路が、構造から消える。

## 引用

> コメントが紐づく相手が live のファイルではなく凍結スナップショットになる。
